# dun.not

Tuttuğum notlar, sınava götürdüğüm formül kağıtları ve konuları çalışmak için kurduğum
etkileşimli siteler. Hepsi ücretsiz, hepsi tarayıcıda açılır.

**Site:** https://feridun35.github.io/dun.not/

## İçerik

- **Ders notları:** el yazısı taramalar. Sitede hafif bir kopya açılır, orijinali indirilebilir.
- **Formül kağıtları:** sınava götürülen tek sayfalık özetler.
- **Etkileşimli siteler:** `siteler/` altında, her biri kendi klasöründe, internetsiz de çalışır.

## Okuyucu

- Konu haritası: notlardaki başlıklardan çıkarıldı, konuya tıklayınca o sayfaya gider.
- Kağıt modu: siyah zeminli taramaları beyaz kağıt üstüne koyu yazıya çevirir.
- Sayfa linki: `oku.html?d=matematik-2#s=34` gibi, doğrudan o sayfayı açar.
- Kaldığın yer tarayıcıda saklanır; hesap, çerez ya da sunucu yok.
